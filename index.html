📱 Application Documentation

Yarlagadda is a next‑gen constituency management and citizen services Android application built for transparent governance, grievance redressal, appointment scheduling, welfare schemes, TTD darshan requests, AI‑powered assistance, and real‑time development monitoring.

✨ Core Features

  • Public Grievance Management with real‑time tracking
  • Citizen Welfare & Service Delivery Dashboard
  • Appointment & Visitor Management System
  • Google Gemini AI Integration (smart summarisation & chat)
  • TTD Darshan Request & Festival Calendar
  • Development Activity Monitoring (geo‑tagged)
  • Election & Survey Management (offline‑first)
  • Secure Authentication (Firebase Auth + encrypted storage)

🛠️ Technology Stack

  • Kotlin + Jetpack Compose (modern declarative UI)
  • Firebase & Firestore (real‑time sync, offline support)
  • Google Gemini AI SDK (on‑device & cloud)
  • Google Maps & Places APIs
  • Room Database + SQLite (offline cache)
  • WorkManager (background sync)
  • MVVM + Repository pattern
  • Encrypted SharedPreferences (secure local data)

✅ Google API Compliance

This website serves as the official public documentation for OAuth consent screen verification, Gemini API usage disclosure, and compliance with Google's limited‑use policy.

🔒 Privacy Policy

Last Updated: 23 May 2026

Your privacy is paramount. This policy describes how the Yarlagadda App collects, uses, and protects your information.

📋 Information We Collect

  • Name, mobile number, email (voluntary)
  • Grievance details, images, location (only with permission)
  • Appointment & visitor logs
  • Device model, OS version, crash reports (for analytics)

🔧 How We Use Your Data

  • Deliver citizen services and process grievances
  • Improve app performance and user experience
  • Provide AI‑assisted responses (via Gemini API)
  • Ensure security and prevent fraudulent use

🤖 Google Gemini API & AI Usage

The app may send user‑generated prompts (e.g., grievance summaries, query) to Gemini AI for generating suggestions or auto‑replies. No personally identifiable information is retained by Google beyond the request context.

🌐 Third‑Party Services

  • Google Firebase (authentication, analytics, Firestore)
  • Google Maps APIs (location picker)
  • Google Gemini API (AI features)

🔐 Data Security & Retention

We use encrypted storage, TLS transmission, and access controls. Data is retained as long as needed to provide services unless deletion is requested.
