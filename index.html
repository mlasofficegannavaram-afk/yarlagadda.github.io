📱 Application Documentation

Yarlagadda is a constituency management and citizen services Android application developed for public administration, grievance management, appointments, welfare services, TTD requests, AI assistance, and development monitoring.

✨ Main Features

  • Public Grievance Management System
  • Citizen Welfare & Service Tracking
  • Appointment & Visitor Management
  • Google Gemini AI Integration
  • TTD Darshan Request Management
  • Development Activity Monitoring
  • Election & Survey Management
  • Offline-first Architecture
  • Secure Authentication System

🛠️ Technology Stack

  • Kotlin + Jetpack Compose
  • Firebase & Firestore
  • Google Gemini AI SDK
  • Google Maps APIs
  • Room Database
  • WorkManager
  • MVVM Architecture
  • Encrypted Shared Preferences

✅ Google API Compliance

This website serves as the official public documentation page for the Yarlagadda Android application and connected Google APIs including Gemini AI services.
